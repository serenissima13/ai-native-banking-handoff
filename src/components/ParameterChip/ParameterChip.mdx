# ParameterChip

A parameter the assistant took from the person's request, shown where it was understood and changeable
in place. It makes the line between *what you said* and *what I assumed* visible.

## Three separate questions

| Property | Answers | Values | Shown by |
|---|---|---|---|
| **Type** · `type` | How is the value changed? | `input` · `select` (Figma also has *Read-only*, used only with Output) | Trailing icon: pencil = input, chevron = select |
| **State** · `state` | Where did the value come from? | `confirmed` · `assumed` · `missing` · `edited` · `output` | Fill, edge (dashed when assumed) and a tag word |
| **Interaction** · `open` / `editing` + browser | What is happening now? | rest · pressed · focused · **open** (select only) · **editing** (input only) | Ring, flipped chevron, the chip turning into a field |

Any State works with either Type: an assumed amount is an input, an assumed deadline is a select.
The trailing icon never changes with the State.

### Type

| Type | Use for | Tap or Enter | Then |
|---|---|---|---|
| Input | Amount | → **editing**: the chip becomes the field, decimal keypad | ✓ or Enter → `onConfirm(draft)` · Escape → `onCancel()` · ✕ empties the field |
| Select | Deadline, Account, Category | → **open**: the parent's menu anchors below, chevron flips | Choosing closes it · Escape or tap outside closes it unchanged |
| Read-only | Output only | nothing — not a button | — |

### State

| State | Meaning | Looks |
|---|---|---|
| Confirmed | The person said it | Brand-subtle fill |
| Assumed | The AI inferred it — please check | Glass, **dashed** edge, amber **"assumed"** tag |
| Missing | Required and absent; blocks the next step | Glass, brand edge, placeholder |
| Edited | The person changed it | Brand-subtle fill, **"edited"** tag |
| Output | The AI calculates it | AI surface, sparkle; always read-only |

## Accessibility

- Input and Select are `<button type="button">`. Select adds `aria-haspopup="menu"` and `aria-expanded`; Input has no popup. Output is a `<span>`.
- Name: `"<parameter>, <visible text>. Tap to change."` — it repeats the visible value and tag word for word, so voice control can use what is on screen (WCAG 2.5.3): *"Deadline, 1 Jul 2027 assumed. Tap to change."* Missing: *"From account, Choose… Required. Tap to change."*
- State is never shown by colour alone: the tag word and the dashed edge carry it (WCAG 1.4.1).
- Focus ring: 2 px offset + 2 px ring (WCAG 2.4.7), also while Open and Editing.
- Touch target: min-height 44 px. Clear and confirm are 32 px visible with a 40 × 44 hit area, no overlap. Above WCAG 2.5.8 (24 px).
- Amounts use tabular figures. `prefers-reduced-motion` turns transitions off; `prefers-reduced-transparency` makes glass solid.
- **Automated check:** axe-core 4.14, WCAG 2.2 A/AA, on the demo in Dark and Light × rest, open and editing — **0 violations**.
